# 素材目录说明

把图片按下面的文件名覆盖进来，游戏会自动使用，**不需要改任何代码**。文件名大小写必须一致。

## units/ 角色

| 文件名 | 用途 | 当前文件 | 说明 |
| --- | --- | --- | --- |
| `pear.png` | 卷梨（资源单位） | 320 × 320 透明 PNG | 戴帽子的小人，手里拿着红果 |
| `guardian.png` | 站神（攻击单位） | 320 × 320 透明 PNG | 戴眼镜的小人，出拳姿势 |
| `yidi.png` | 易帝（敌人） | 320 × 320 透明 PNG | 黄色袋鼠，手拿球拍 |

要求：背景透明、主体居中、四周留一点空白。单位按格子的 88%、敌人按 82% 等比缩放（约 60 像素高），
细节太小会看不清，建议主体占满画布 85% 左右。

> 单位和敌人现在站在**同一条通道**里（一条通道一行），纵向有小幅错位避免完全重合。
> 主角和敌人都别在图里画「地面阴影」，游戏会另画一个椭圆影，位置跟格子对齐。

## bullet/ 子弹

| 文件名 | 用途 | 当前文件 |
| --- | --- | --- |
| `paddle.png` | 站神打出去的球拍 | 200 × 200 透明 PNG |

站神的攻击表现是「挥手打拍子」：开火时手上会出现一支球拍沿弧线扫过，
球拍飞出变成子弹，边飞边转。这个文件同时用于**手上的拍子**和**飞行的子弹**，
所以留白不要太多，拍面要完整。

## bg/ 背景

| 文件名 | 用途 | 当前文件 |
| --- | --- | --- |
| `bg.png` | 棋盘底图 | 800 × 640 |

棋盘是 **10 列 × 4 行、每格 72 像素（720 × 288，5:2）**。底图会等比铺满并居中裁切，不会拉伸变形，
所以什么比例都能用，但 5:2 左右最不容易裁掉重点。

当前底图做了柔化处理，并且只以 55% 不透明度叠在下面当质感 —— 上面盖的是四条深浅交替的草地通道，
通道必须一眼分得清，底图太抢戏会让人以为有八条路。

## ui/ 界面图标

预留目录。目前铲子图标是组件内联 SVG（`UnitBar.vue`），其余界面用纯 CSS 绘制，不依赖图标文件。
后续做皮肤或自定义图标时放这里。

## audio/ 音频

| 文件名 | 用途 |
| --- | --- |
| `bgm.mp3` | 背景音乐（循环播放） |
| `shoot.wav` | 站神挥拍 |
| `build.wav` | 放置单位 |
| `pear.wav` | 梨光产出 |
| `upgrade.wav` | 强化卷梨 |
| `remove.wav` | 铲子收回单位 |
| `hit.wav` | 敌人受击 / 抵达终点（可以放"饿啊"） |
| `win.wav` | 通关 |
| `lose.wav` | 失败 |

**全部可选**。文件不存在时，游戏会用 Web Audio 实时合成替代音，不会报错、不会静音卡死。
放进去就会自动优先播放。

## 缺图会怎样

任何一张图缺失或加载失败，都会自动退化成程序化绘制的占位图形（卷梨是一颗带叶子的绿梨，
站神是蓝帽小哨兵，易帝是橙团子，子弹是一颗蓝色光点），游戏照常运行。
所以可以边玩边补素材。

## 换图后画面比例不对怎么办

角色在格子里的显示比例由 `src/config/units.ts` 的 `drawScale` 控制（0~1，越大越大），
敌人的在 `src/config/enemies.ts`。改一个数字，刷新页面就能看到效果。
